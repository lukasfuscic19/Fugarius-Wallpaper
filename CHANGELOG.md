# Changelog

## [0.2.0] — 2026-06-03

### Fixed
- Panorama auto-fit: image center aligns with virtual desktop center (1:1 VD mapping; no top/bottom edge pinning).
- Default window size and scrollable sidebar; status bar always visible.
- Per-monitor zoom, rotation, and offsets restored (auto-fit still sets a shared baseline).

### Added
- Project icon (`assets/icon-source.png`, Freedesktop hicolor tree).
- Packaging: Fedora RPM (AppStream), AppImage, desktop entry, `restore_panels.sh`.
- Release assets: `fugarius-wallpaper-*.rpm`, `Fugarius-Wallpaper-*-x86_64.AppImage`.

## [0.1.0] — 2026-06-02

- Initial release: multi-monitor panorama wallpaper for KDE Plasma (Wayland).
